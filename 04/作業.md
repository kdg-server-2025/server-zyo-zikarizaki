##　4回目の授業

- volume について
    - コンテナの /var/www/html（WordPress）や /var/lib/mysql（MariaDB）といった内部のデータディレクトリを、ホスト側に永続化するため。

- yaml について
    - 構造化データを記述するための人間に読みやすいフォーマット

- conpose の構文、書き方
    - 複数の Docker コンテナをまとめて管理・起動・停止できるツール
    - docker-compose.yml にまとめておけば、1コマンドで同時に起動・停止・構築できる

- ipアドレスとport
    - コンピューターの通信は ip アドレスと port を使って行うことが多い

- wordpress を構築する
    - image: wordpress:latest
        - Docker Hub の公式 WordPress イメージを使う

    - container_name: whitehouse_wordpress
        - コンテナ名を指定。指定しないと自動で ディレクトリ名_wordpress_1 みたいになる

    - ports: "8000:80"
        - ホストのポート8000 → コンテナの80番ポートに転送
        - ブラウザで http://localhost:8000 にアクセスできる

    - mariadb:latest イメージを使って DB コンテナを作る
        - コンテナ名は whitehouse_db
    
    - db_data という名前付きボリュームを /var/lib/mysql にマウント
        - MariaDB の実データ（記事・ユーザー情報）が保存される場所,これも永続化のため
